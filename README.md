# Fitness Gym React Website Demo

A responsive, dark gym landing page built with React, Vite, and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open a terminal inside it.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment

Run `npm run build`. The production website is generated in `dist/`.

## Customize

- Edit page content and plans in `src/main.jsx`.
- Change colors, spacing, and responsive layouts in `src/styles.css`.
- Gym plan prices are illustrative demo prices; confirm real pricing before launch.
- Photos are loaded from Unsplash, and Google Fonts are loaded online.
- The join form is front-end demo behavior only. Connect an API, database, email service, or WhatsApp link to receive real enquiries.
- Replace the placeholder social links and add the gym's real address, phone number, hours, and branding before production.
